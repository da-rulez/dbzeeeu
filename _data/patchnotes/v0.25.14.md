## v0.25.14: Login over HTTPS [Patch]

### Fixed
- **Login, registration and every account call now go over HTTPS** to api.dbzee.eu with certificate validation. The client has no plain-HTTP path to the account server any more, and the server refuses credentials sent in the clear instead of redirecting them.

All sessions are being signed out once as part of this change, so you will log in again. If you have used your DBZee password anywhere else, this is a good moment to change it.
