## v0.37.3: Unlink Discord and delete with Discord [Patch]

**Discord accounts**
- Every linked account can now unlink Discord from the character screen.
- Accounts with a password go back to logging in with username and password.
- Accounts that only sign in with Discord have nothing else to log in with, so for them unlinking deletes the account and all its characters. The game warns you in red and asks you to type DELETE first.
- Unlinking is always confirmed on Discord itself: you sign in with the same Discord account and type the code the game shows. Another Discord account cannot do it.
- Discord-only accounts can now delete a character too, confirmed the same way on Discord. Before, it asked for a password they did not have.
- The Discord page tells you plainly what is about to happen.
