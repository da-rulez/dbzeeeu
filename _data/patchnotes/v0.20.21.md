## v0.20.21: Tournament Tab Tidy-Up [Patch]

**The server tournament is now called Budokai Tenkaichi**, and it is the only one you can host. The second entry next to it was a development test rig that was never meant to be on that list.

**Hosting your own** got a pass over its form:

- The arena dropdown matches the rest of the interface, and reads the arena name instead of the scene it came from. Budokai Tenkaichi is the only finished arena, so it is the only pick for now. More will join it.
- The rules checkboxes were invisible, a dark box on a dark panel with no way to tell whether a rule was on. They have a real box now, orange when ticked, in the same font and size as everything else.

**Active effects tooltip.** Hovering a status effect no longer draws a grey slab behind the window. It is the same tooltip the technique bar uses, down to the coloured numbers: effect name in green or red by whether it helps you, time left, source, and what each part of it is doing.
