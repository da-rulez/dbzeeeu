## v0.19.15: Per Direction, Like It Should Be [Patch]

### Tools
- **The per-spell hit-area offset now works per direction.** A single value could never be right: the offset is a world vector and the tiles are held upright, so it reads sideways off an east/west lane and along a north/south one. There is now a North/South/East/West pair, with the flat pair kept as the fallback when per-direction is off.
- Both the overlay's own per-direction offsets and the new per-spell ones resolve through one shared rule, so they cannot disagree about which way "east" is.
