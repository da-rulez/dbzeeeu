## v0.16.59: The New Map Engine Goes Live [Release]

The overworld and Muscle Tower now run on the new native map system, completing the map toolkit project.

- Collision equivalence with the old maps is machine-verified (every legacy collision shape covered, zero phantom walls), so everything should feel exactly the same, just faster.
- Server memory per map is down 56 percent, draw calls halved, render load roughly halved.
- Tiled and the YATI importer are fully removed; all maps are now authored with the in-editor MapKit tools.
