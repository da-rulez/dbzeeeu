## v0.25.18: The client knows its own version [Hotfix]

### Fixed
- **A leftover file could make an up-to-date client report an old version** and get turned away as outdated. An older launcher left a version stamp beside the game executable, and the client read that instead of its own build. The client now uses the version it was built with, and the launcher clears files it does not own from the game folder.
