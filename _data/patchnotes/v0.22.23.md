## v0.22.23: Overnight Round 8 [Patch]

- The game client no longer opens a local admin control port on the player's machine. During the connect handshake a client briefly looks like the server to the engine, and the admin listener (meant for the dedicated server only) was binding 127.0.0.1:9001 on every client. It is now gated on an explicit server-only flag, so only the real game server ever opens it.
Verified: the dedicated server still opens the admin port; a freshly connected client opens nothing. A ten-minute eight-bot combat soak ran with zero server script errors and steady frame times.
