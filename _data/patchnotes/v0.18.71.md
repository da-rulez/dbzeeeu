## v0.18.71: Back In Place [Patch]

### Fixes
- **Scenery is back exactly where it was placed.** Last patch corrected the map editor's preview, which was drawing objects six pixels below where the game puts them. That told the truth but left everything already placed reading six pixels high, since it had all been positioned by eye against the old preview. Every placed object has been moved back to where its author actually saw it, across every map.
- The preview shown while dragging an object had its own copy of the same six-pixel error, so it sat below where the click landed. Both now agree with the game.

### Under the hood
- Arrow keys nudge the selected object, marker or piece of furniture, stepping by whatever snap is set: one pixel, quarter tile, half tile or a full tile. A whole box selection moves together as a single undo.
- Furniture depth is one rule everywhere now, the same position sorting everything else uses.

Nothing moved that you did not move.
