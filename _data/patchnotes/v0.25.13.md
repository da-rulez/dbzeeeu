## v0.25.13: Signed, HTTPS-only updates [Patch]

### Fixed
- **The launcher now trusts only signed updates over HTTPS.** Game files and the update manifest come from the official release feed over TLS with certificate validation and no plain-HTTP path. The manifest is signed with a release key that never leaves the build machine; the launcher carries only the public half and refuses any manifest, file or redirect that does not check out, keeping your previous version playable instead.

Get the new launcher from the website: an older launcher cannot safely update itself to this one.
