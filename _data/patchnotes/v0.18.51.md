## v0.18.51: Earn Your Build [Patch]

### Minigames
- **New match rule: equalize at the start only.** Everyone begins on the same base stats, exactly like a fully equalized match, but every level you buy with orbs you earn inside the match counts in full. The fight starts even and is decided by what you build in it.
- **Base Assault now runs on that rule.** Walk in with nothing, farm, spend, and the build is yours for the length of the match. It all reverts when you leave, like anything else picked up in a match.
- The old equalize rule is unchanged and still available: a fixed stat block for the whole game, where nothing you buy mid match moves the dial. Pick one per game in the editor.
- The two rules cannot fight each other. If a game somehow has both set, the fixed block wins.

Have fun out there.
