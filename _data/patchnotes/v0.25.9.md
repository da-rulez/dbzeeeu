## v0.25.9: Character creation and chat hardening [Hotfix]

### Fixed
- **A character's look must belong to its race.** The server now checks body, hair and facial hair against the chosen race's own lists, the same lists the creation screen offers, so a crafted request can no longer pair one race with another's body.
- **Chat is one line.** Line breaks and control characters in a chat message become spaces, so a message can no longer be made to look like a second, official line.
