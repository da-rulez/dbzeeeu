## v0.22.32: Server groundwork + login and upkeep fixes [Patch]

- Groundwork for running loci (dimensions) on a second server process, so heavy NPC fights inside them no longer compete with the overworld for the same CPU core. The hand-off between processes is built and tested but not switched on for players yet; nothing changes in how you enter or leave a locus in this version.
- Login: the "already logged in" check now accounts for every server process, so a stale session can never be cleared while your character is actually still in play.
- Weekly upkeep, the official tournament schedule and the Dragon Ball tracking each run exactly once server-side (they could have run twice once the second process is enabled).
- Release tooling: server updates and rollbacks now move every game process together.
