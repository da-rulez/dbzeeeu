## v0.23.0: The client keeps only the picture

**Under the hood**
- The game client now carries only what it needs to draw and to talk to the server: art, sounds, maps as you see them, the interface. Spell numbers, item stats, enemy stats and drop tables, recipes, shop stock, loot rules and the server's own logic no longer ship inside the client at all.
- What your screen needs at any moment (the cost and cooldown of a technique you know, the stats of an item in your bag, the bestiary page you have unlocked) is sent to you by the server as you play. Nothing changes in what you see; the difference is where it comes from.
- Presentation data (names, descriptions, icons, animations) is delivered at login as a single signed and encrypted package. A client that cannot verify it will not start.
- Enemies and ground items now appear on your screen because the server tells your client about them, not because the map already knew where they would be.

**Fixes**
- The encrypted client build is checked before every release: any server code or game content that slips in fails the release.
- Every client-to-server request is now exercised with hostile inputs before a release ships.
