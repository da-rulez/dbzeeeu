## v0.18.87: Clean Cast [Hotfix]

### Fixes
- **A refused cast no longer plays first and fails after.** Casting a technique that needs a target without one used to run the wind-up animation and light up the charge aura, and only then tell you there was no target. It now refuses immediately, and the aura goes with it.
- **Spirit Bomb and Death Ball charge above the canopy.** Gathering one under a tree drew the ball behind the leaves, which looked wrong for something held in the sky. It now sits above overhanging scenery while you charge. Once thrown it sorts normally again, so it can still pass behind things on the way down.
