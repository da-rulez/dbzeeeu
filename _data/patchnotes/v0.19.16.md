## v0.19.16: Tidier Offsets [Patch]

### Tools
- **Hit Art Offset Per Direction is a checkbox now**, and the eight North/South/East/West fields only appear once it is ticked, instead of sitting there empty whether or not they apply.
- **The spell preview keeps up while you type.** Number fields used to reach it only once the edit was committed, so a typed value looked like it did nothing until focus moved.
