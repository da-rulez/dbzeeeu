## v0.22.20: Overnight Round 5 [Patch]

- Parties no longer disband when a member changes map. Entering a locus, a house or a minigame used to run the same cleanup as logging out, so the party silently dissolved on every warp.
- Party invites, invite results and party state now reach members standing in a different map (they used to error on the far client and never show up).
- Guild vault updates reach guild members in every map, not just the one where the change happened.
- Fixed a client error at login when a system message arrived before the map had loaded.
- Fixed "Node not found" client errors when a nearby player spawned (ball count, PvP zone state and posed-animation updates were sent one frame before the player itself).
- Party polling no longer writes a line to the server and client logs every second per player.
Verified: two-bot harness formed a party, warped the leader to another map, left and re-invited across maps with clean logs on both clients and the server.
