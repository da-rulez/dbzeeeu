Download & play

Grab the launcher.

The DBZee launcher is free. It pulls the latest client build, keeps it up to date, and drops you straight into the login screen.

System requirements

  • OS: Windows 10+ (64-bit) or a recent 64-bit Linux distro.
  • CPU: any dual-core from the last decade.
  • GPU: integrated graphics are fine. Dynamic Lighting and Shader Effects can each be toggled off under Escape → Video on lower-end machines.
  • RAM: 2 GB free.
  • Disk: ~250 MB after install.
  • Network: a stable connection — the game is fully online.

Getting started

  • Run the launcher. It will fetch the current client build and update itself when new versions ship.
  • Create an account from the login screen.
  • Roll a character. Pick a name. You'll do the tutorial during the first scene.
  • Find a guild or start one once you've found your footing — the Dragon Ball pedestals are a guild feature.

Troubleshooting

  • Browser blocks the download: the launcher is currently served over plain HTTP, so some browsers warn or block from an HTTPS page. Click "Keep" / "Download anyway" in the browser's download bar.
  • Can't connect: the auth and game servers run separately. If login works but world load hangs, check your firewall against the server port shown in the launcher.
  • Auras look flat: open Escape → Video and make sure Shader Effects and Dynamic Lighting are both on.
  • Performance dips in towns: drop Dynamic Lighting first; it's the heavier of the two toggles.
  • Linux: launcher won't run: make sure it's executable (chmod +x dbzee_launcher) and your distro has up-to-date Vulkan / OpenGL drivers.
