Heads up: the web build is for trying the game out and may run noticeably slower than the native client. For long sessions we recommend the native download for your OS.

System requirements

  • OS: Windows 10+, macOS 11+, or a recent 64-bit Linux.
  • CPU: any dual-core from the last decade.
  • GPU: integrated graphics are fine. Dynamic Lighting and Shader Effects can each be toggled off under Escape → Video on lower-end machines.
  • RAM: 2 GB free.
  • Disk: ~250 MB after install.
  • Network: a stable connection — the game is fully online.

Getting started

  • Run the client. Pick a server (you can change later).
  • Create an account from the login screen.
  • Roll a character. Pick a name. We'll do tutorial during the first scene.
  • Find a guild or start one once you've found your footing — the Dragon Ball pedestals are a guild feature.

Troubleshooting

  • Can't connect: the auth and game servers run separately. If login works but world load hangs, check your firewall against the server port shown in the client's settings panel.
  • Auras look flat: open Escape → Video and make sure Shader Effects and Dynamic Lighting are both on.
  • Performance dips in towns: drop Dynamic Lighting first; it's the heaviest of the two toggles.
  • Web build won't start: use a Chromium-based browser, allow WebGL2 / WebGPU, and disable any aggressive ad blocking on the page.
