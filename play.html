Download & play

Play in your browser, or grab the launcher.

Both are free and play in the same world. The browser version needs no install and no account to start: press Play as guest. The launcher pulls the latest client build, keeps it up to date, and runs a little faster.

System requirements

  • OS: Windows 10+ (64 bit). Linux and macOS builds are paused.
  • CPU: any dual core from the last decade.
  • GPU: integrated graphics are fine. Dynamic Lighting and Shader Effects can each be toggled off under Escape → Video on lower end machines.
  • RAM: 2 GB free.
  • Disk: ~250 MB after install.
  • Network: a stable connection. The game is fully online.

Playing in the browser

  • The first visit downloads about 35 MB; your browser keeps it, so the next visits start much faster.
  • Chrome and Edge also keep the prepared graphics between visits, so they start the quickest. Firefox prepares them again each visit.
  • Play as guest keeps your character on that browser. Link Discord from the character screen to keep it everywhere and unlock all three character slots.
  • Phones and tablets are not supported yet: the game needs a keyboard.

Smoother play in the browser

  • Use Chrome or Edge if you can. They start the quickest, because they keep the prepared graphics between visits. Firefox works too, it just prepares them again every time you open the game.
  • Turn on graphics acceleration. Without it the browser draws the game on your processor and it will stutter. Chrome: Settings → System → Use graphics acceleration when available. Edge: Settings → System and performance → Use graphics acceleration when available. Firefox: Settings → General → Performance, untick Use recommended performance settings and tick Use hardware acceleration when available. Restart the browser afterwards.
  • Switch off battery savers for the game. Chrome's Energy saver (Settings → Performance) and Edge's Efficiency mode (Settings → System and performance) lower the frame rate.
  • Laptop with two graphics chips (an Intel or AMD chip in the processor plus an NVIDIA or AMD card): make sure the browser runs on the card. Windows 11: Settings → System → Display → Graphics, pick your browser (or add it with Browse) and set it to High performance. Windows 10: Settings → System → Display → Graphics settings, add the browser, Options, High performance. With an NVIDIA card you can also open the NVIDIA Control Panel → Manage 3D settings → Program Settings, choose the browser and pick High-performance NVIDIA processor. Close the browser fully and open it again.
  • Check which chip is used. Type chrome://gpu (or edge://gpu) in the address bar: WebGL2 should say Hardware accelerated, and the GL_RENDERER line names the chip. In Firefox, about:support lists it under Graphics.
  • On a laptop, plug it in and set Windows to Best performance (Settings → System → Power). On battery many laptops slow the graphics down.
  • Close other heavy tabs (video, other games), and press F11 for full screen.

Getting started

  • Play in the browser, or run the launcher. It will fetch the current client build and update itself when new versions ship.
  • Create an account from the login screen.
  • Roll a character. Pick a name. You'll do the tutorial during the first scene.
  • Find a guild or start one once you've found your footing. The Dragon Ball pedestals are a guild feature.

Troubleshooting

  • Can't connect: the auth and game servers run separately. If login works but world load hangs, check your firewall against the server port shown in the launcher.
  • Auras look flat: open Escape → Video and make sure Shader Effects and Dynamic Lighting are both on.
  • Performance dips in towns: drop Dynamic Lighting first. It's the heavier of the two toggles.
